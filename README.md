# Конструктор модели МТФ

Версия 1.1

Инструмент для расчёта экономики молочно-товарной фермы и сборки документа
«Модель проекта (term sheet)». Работает в браузере, без сервера и без сборки.


## Новое в версии 1.1

- **Мультивалютность.** Каждая статья капзатрат и цена нетели могут задаваться в ₸, €, $ или ₽. Курсы — на вкладке «Вводные».
- **Три способа задания удоя:** на фуражную корову за год, за лактацию 305 дней, среднесуточный на дойную. Пересчёт автоматический, расчётное значение показывается под полем.
- **Гибкое размещение молодняка** в свободных местах коровника, пока стадо не вышло на мощность.
- **Капзатраты и операционные расходы** — добавление и удаление статей прямо в таблице.
- **ФОТ одной суммой** или штатным расписанием, с опцией масштабирования под фактическое поголовье.
- **Корма в трёх режимах:** по нормам, своя база (га на корову или фиксированная площадь), одной суммой.
- **Оборотный кредит** подбирается автоматически с лимитом; при его исчерпании выводится предупреждение.
- **Разнесение капзатрат по годам** строительства.
- **Сравнение сценариев** — сохранение расчёта и таблица сопоставления.
- **Проверки согласованности вводных** — доля дойных против мест в коровнике, порядок величины цены нетели, сумма распределения капзатрат.
- **Презентабельный документ** — титульный лист, тёмные шапки таблиц, чередование строк, корректные разрывы страниц при печати в PDF.

## Запуск

Локально — открыть `index.html` в браузере.

На GitHub Pages:
1. Создать репозиторий, залить содержимое папки в корень.
2. Settings → Pages → Source: Deploy from a branch → main / (root).
3. Открыть выданный адрес.

## Структура

```
index.html          страница
css/style.css       оформление
js/config.js        справочники и значения по умолчанию
js/subsidies.js     реестр мер господдержки
js/calc-herd.js     движение стада (помесячная модель)
js/calc-econ.js     капзатраты, расходы, выручка, субсидии
js/calc-fin.js      кредит, денежные потоки, NPV / IRR / DSCR
js/doc.js           шаблоны текста документа
js/export.js        выгрузка в Word, PDF, CSV, JSON
js/ui.js            интерфейс
```

## Что где править

**Добавить статью капзатрат** — `js/config.js`, массив `MTF.capexItems`.
Поле `unit`: `sum` (фиксированная сумма), `place` (цена за скотоместо × количество
мест из `capacity`), `head` (цена за голову × стартовое поголовье).
Поле `group` определяет процент финансирования: `prep`, `build`, `equip`, `herd`.

**Изменить штатное расписание** — `js/config.js`, массив `MTF.staff`.
Должности также добавляются и удаляются прямо в интерфейсе.

**Добавить статью операционных расходов** — `js/config.js`, массив `MTF.opexItems`.
Поле `base`: `head` (на голову в год), `cow` (на фуражную корову), `sum`
(фиксированная сумма), `milk` (на литр).

**Добавить меру поддержки** — `js/subsidies.js` или кнопка «Добавить меру поддержки»
в интерфейсе. Типы: `per_liter`, `per_head`, `capex_pct`, `fixed_year`, `rate_sub`.
Поле `conflictsWith` — список id мер, с которыми она не совмещается; при
одновременном включении инструмент выдаёт предупреждение, но не блокирует выбор.

**Изменить текст документа** — `js/doc.js`, массив `MTF.docSections`, либо кнопка
«Править шаблоны» на вкладке «Документ». Плейсхолдеры в фигурных скобках
подставляются из расчёта автоматически.

## Как работает расчёт стада

Помесячная модель. Нетели завозятся по графику, отеляются, входят в основное
стадо. Коровы выбраковываются равномерно по году. Приплод делится на тёлочек и
бычков; тёлочки либо идут на ремонт стада, либо продаются. Пока поголовье ниже
проектной мощности, на ремонт оставляются все тёлочки; после выхода на мощность —
только на замещение выбраковки.

Фуражное поголовье = дойные + сухостойные. Доля сухостоя считается от длины
сухостойного периода и интервала между отёлами. Удой задаётся на фуражную
корову — это отраслевой стандарт и база для субсидий.

## Ограничения версии 1.0

- Капитальные затраты относятся целиком на первый год. Разнесение по этапам
  строительства не реализовано.
- Оборотный кредит не моделируется отдельно — кассовый разрыв показывается,
  но не закрывается автоматически.
- Сезонность цены на молоко не учитывается.
- КПН не рассчитывается (для сельхозпроизводителей обычно льгота).
- Ставки субсидий в реестре — заготовки, помеченные статусом «проверить».
  Перед использованием их нужно сверить с действующими правилами субсидирования.

## Сохранение работы

Кнопка «Сохранить проект» выгружает файл `.json` со всеми параметрами.
«Открыть проект» загружает его обратно. Внутри сессии данные держатся
автоматически, но при закрытии вкладки теряются — сохраняйте файл.
